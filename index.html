Missing cost centres — recommendations

Cost centres of the selected project that are not in the to-be hierarchy. The hierarchy is organisational, so each recommendation places the cost centre next to the other cost centres of the same person responsible (former as-is neighbours act as a secondary signal). Approve the recommendation, override the parent first, or reject it.

Edit the to-be hierarchy

Both views edit the same working copy and stay in sync. Live view: drag a node onto a group to move it; use the row buttons to rename (✎), add a child group (＋) or delete (✕). Deleting a group moves its children up one level; deleting a cost centre returns it to the missing list. Table view: edit names and change parents inline.
